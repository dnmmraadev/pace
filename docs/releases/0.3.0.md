# PACE 0.3.0

Prepared locally on 2026-10-07. This document records release-ready source and a Windows artifact; it does not publish a GitHub release or tag. The latest published download remains 0.2.0.

## Learning changes

- Deterministic variable practice for 16 quantitative competencies, plus three contextual checks, throughout the lessons, lab and review.
- Concept proficiency requires at least five distinct instances and 80% first-attempt accuracy in the latest eight. Fixed questions and repeated/corrected instances cannot inflate evidence. Completion remains separate; the heuristic has no established psychometric validity.
- Eight-item diagnostic spanning metrics, bookings, commercial decisions and data; recommendations never lock content.
- Thirty bilingual interview questions across 15 junior analyst categories. Open answers are committed before rubric/model feedback and remain ungraded.
- Downloadable raw reservations and channel lookup, a realistic Excel management-summary assignment, explicit segment forecasting assumptions, error/bias and scenario ranges.
- Transfer assessments in a 180-room corporate hotel and 64-room leisure property, alongside the primary roughly 900-room resort. Decisions address contribution, groups/displacement, room types, restrictions, wash and overbooking risk with context.

## Compatibility and limits

The version-1 progress key, existing lesson/question IDs and historical completion, attempts, review dates and capstone remain readable. Optional generated metadata and written reflections are additive. Broader diagnostic assessments use fresh identifiers rather than reinterpreting old answers. Historical fixed-question mastery becomes retained practice history; learners need new variable evidence for proficiency. No destructive migration or backend is introduced.

ES/EN coverage remains complete. Excel tasks check selected results after external workbook work; PACE does not execute Excel or assess workbook technique. Commercial reasoning uses self-review, and the transparent forecast is a teaching model rather than an RMS. The application remains local-first with no account or AI API.
