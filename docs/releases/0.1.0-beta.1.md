# PACE 0.1.0-beta.1 — First public desktop beta

PACE is an English Hotel Revenue Management learning workstation using only synthetic data for a roughly 900-room resort.

## Download and run

Download **PACE-0.1.0-beta.1-Windows.exe** from the assets below and launch it on Windows x64. This portable application needs no Node.js installation, account or development server.

The executable is unsigned; Windows may display a reputation prompt. SHA256SUMS.txt contains the executable checksum. In PowerShell, use Get-FileHash with -Algorithm SHA256 to compare a downloaded file.

## Included

- 17 lesson loops, with detailed foundations in mental models, hotel metrics, booking behavior and forecasting.
- Calculation feedback, retrieval practice, revenue decisions and a spaced review queue.
- Separate completion and demonstrated-mastery tracking, persisted locally.
- Formula sheet, glossary, command composer and Ctrl/Cmd + K navigation.
- Spreadsheet simulations and synthetic CSV export.
- Morning workflow, revenue meeting, capstone and interview practice.
- Graphite / Teal desktop workspace with the supplied PACE identity.

## Why this version

This is **0.1.0-beta.1**, following the documented [version policy](https://github.com/dnmmraadev/pace/blob/v0.1.0-beta.1/docs/versioning.md). The leading zero signals initial development; beta.1 identifies the first public evaluation build. The former 1.0.0 package value was an unpublished development placeholder.

## Validation

Learning tests, TypeScript/production build and the desktop browser smoke check passed. The packaged Windows renderer was checked for launch, version and restart persistence. See the tagged source and GitHub checks for reproducible source verification.

## Known limits

- Later modules contain substantive initial content and are less developed than the foundations.
- Written commercial reasoning is compared with model responses, not automatically graded for business quality.
- Progress is local with no cloud backup or automatic browser-to-desktop transfer.
- Windows x64 is the packaged target; packaged macOS/Linux support is unverified.
- No mobile product, professional certification or production hotel-data integration is provided.
- The public repository retains its existing rights notice; a distribution license has not been selected.

Report reproducible issues using the repository templates. Use only synthetic examples and do not attach personal progress or application profiles.
